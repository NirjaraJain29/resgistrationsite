🎉 TechFest 2025 – Event Registration Portal

A sleek and functional Event Registration Portal built using HTML, CSS, and JavaScript for TechFest 2025.
It allows users to register for events and view all registered participants — showcasing the essentials of front-end web development with a simple yet powerful interface.


---

✨ Features

📝 Interactive registration form for participants

💾 Stores and displays registered participant details

🎨 Clean, responsive design using pure CSS

⚡ Fully client-side — no frameworks, just HTML, CSS, and JS

🔍 Easy navigation and dynamic data rendering



---

🛠️ Tech Stack

HTML5 – Structure

CSS3 – Styling and layout

JavaScript (ES6) – Logic, storage, and interactivity
